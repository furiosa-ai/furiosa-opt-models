# Rust reference

The reference is built from `main`.

- [`furiosa_opt_models`]({{ config.site_url }}api/rust/furiosa_opt_models/index.html): numerical operations, modules, model definitions, the model registry and how weights load.
- [`furiosa_opt_engine`]({{ config.site_url }}api/rust/furiosa_opt_engine/index.html): load options, launches and decoder calls. Frameworks call the engine through its Python module ([Python reference](python.md)), so this reference also documents its internal items, for developers adding a model.

# furiosa-opt-vllm

[![Python reference](https://img.shields.io/badge/reference-Python-blue)](https://developer.furiosa.ai/furiosa-opt-models/reference/python/)

Use vLLM's Python and HTTP APIs with model functions on RNGD.
The plugin registers the RNGD platform and adapts vLLM requests to the engine.

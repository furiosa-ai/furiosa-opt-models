# furiosa-opt-sglang

[![Python reference](https://img.shields.io/badge/reference-Python-blue)](https://developer.furiosa.ai/furiosa-opt-models/reference/python/)

Use SGLang's Python and HTTP APIs with model functions on RNGD.
The plugin registers the RNGD platform and adapts SGLang requests to the engine.
